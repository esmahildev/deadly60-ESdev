# Deadly 60 - Extended Version (class demo)

**Deadly 60 Extended Version by ESMAHIL DEV and CLAUDE CODE** - an extension of *Deadly 30* (original game by Ignatus Zuk and Gonzossm, published by Headup Games) from 30 to 60 nights.
This private repository is only for showing the project to my teacher; it is not a public release.

## How to play
1. Download **Deadly60_Game.zip** (click the file, then the download button).
2. Unzip it. It contains one file: **Deadly 60.exe**.
3. Double-click **Deadly 60.exe**. Nothing else needs to be installed. The first start takes a few seconds while the game unpacks itself into your own `%LOCALAPPDATA%\Deadly60` folder.
4. Windows SmartScreen may warn because the file is not code-signed: choose **More info -> Run anyway**.
5. Close the game with the window's X button so your progress is saved (it is stored in the same `%LOCALAPPDATA%\Deadly60` folder).

Requires Windows 10/11 on an Intel/AMD (x64) PC. Windows-on-ARM laptops were not tested. If the window stays black, the launcher tries other graphics modes automatically.

## What is new compared with Deadly 30
- Nights 31-60 with new zombie kinds, event nights, supply drops and a Night 60 finale.
- **The Engineer** (4th survivor) joins at the start of **Night 29** - press 4 to select him, Q to swap his weapon.
- Four new weapons, unlocked by survived night: **Wave Cannon 30, Air Blast Cannon 33, Flamethrower 37, Tesla Rifle 40** (shop > NEW GUNS). Each can only be bought by its owner survivor.
- Weapon upgrades (U / I / O), perks (J / K), defences (G / B / T), Mk II evolution (L, day 40), help (H) - available at the base in the daytime from day 30.
- **C** inside the base sends the squad to the defence spots; press **C** again to make them follow you.
- Restyled soldiers, new title (DEADLY 60), new credits lines, new sound effects.

## Notes
- The game starts at Night 1 like the original; reaching the new content takes many nights.
- Status: checked with static checks and short smoke tests; it is not fully play-tested.
